If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key facts: primary palette is Korps Green (#032819) + Korps Gold (#ffbf4d) on a cream paper background (#f7f4ee), never pure white. Body/doc font is Source Code Pro everywhere in-character; the display font (Black Ops One) is reserved for out-of-lore surfaces only (landing page, deck titles). No rounded corners, no soft shadows, no gradients — square corners and a hard "rubber stamp" offset shadow. See readme.md's Content Fundamentals and Visual Foundations sections before writing any copy or new UI.
